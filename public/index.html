本地文件

格式为 .mianxie.json（版本化 JSON，一个文件里可以装单个花样或一整份备份）。 iPad / iPhone 上会弹系统分享面板，可直接存到「文件」App，或用 AirDrop、微信发出去。 另外，执行「新建 / 载入文件 / 载入示例」这类会覆盖画板的操作前，系统会自动留一份底，点「恢复上次内容」可找回。

工具

填色方法：点一下格子选中它（也可以按住拖出一块区域），再点下面的颜色就能上色。
画笔：按住拖动可以像真笔一样连续画（支持 Apple Pencil 压感笔迹、鼠标拖拽）。
套索：按住自由圈选任意形状，圈完就能复制 / 剪切 / 粘贴 / 填色。
选区：框选或套索后，在选区里按住拖动就能直接搬走这块内容；点「复制 / 剪切」也会变成可拖动的浮动块，拖到位置后点「放下」。

注释 0

选择「注释」工具后点击任意格子添加；同一格再次点击可编辑。可在“箭头标注”和直接叠在图案上的“后期文字”之间切换，导出图片时自动保留。
